# Personal Resume Website

A personal resume website built with [Quarto](https://quarto.org/) and hosted on [GitHub Pages](https://pages.github.com/). This repository was originally created as part of an in-class demonstration, but has evolved into a convenient and attractive place to bring together my resume and a few example projects onto a single website.

**Live site:** https://tyler-johnston-1.github.io/resume/

## Repository Files

- `Pages` - Includes .qmd files for each page of the website, home page (index.qmd), projects, resume, and links.
- `index.qmd` - Main home page, includes links to examples projects & resume
- `assets/` - Contains additional projects, documentation, images, and other pages.
-`styles.css` - CSS website configuration code
- `_quarto.yml` - Additional site configuration and metadata
